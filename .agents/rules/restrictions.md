# 🚫 Strict Restrictions & Prohibitions

Non-negotiable constraints for all AI agents and developers operating in this repository.

---

1. **NO Arbitrary Color Modification**:
   - Never mutate, adjust hue, or mathematically interpolate the original 159 Wada Sanzo color definitions.
   - Do NOT add synthetic or imaginary color entries to `data/wada_colors.json`.

2. **NO Blind Grep Searches for Code Symbols**:
   - Use `codebase-memory-mcp` first (`search_graph`, `trace_path`, `get_code_snippet`) for locating functions, CLI commands, and architectural pathways.

3. **NO Unverified Contrast Combinations**:
   - Never generate digital UI palettes where text and background fail WCAG AA (4.5:1 for body text, 3:1 for large headings).
   - Monochromatic washi ivory / sumi carbon bridges are required for readable surfaces.

4. **NO External CLI Runtime Dependencies**:
   - Keep the CLI fast and self-contained; do not add heavy external dependencies to `package.json` `dependencies`.
